# OrionToggleButton

## Usage

`<o-toggle-button>` displays a customisable persistent state button.

A toggle button is a persistent state button that allows you to enable or disable a single option.
Unlike a standard action button, it retains its state after interaction and visually reflects whether the option is active or inactive.
