# OrionToggleButtonGroup

`<o-toggle-button-group>` is a set of persistent state buttons that allow selecting one or more options from multiple choices.
It must be used with `<o-toggle-button>` components as children.

Each button clearly indicates its state, active or inactive, providing an intuitive interface for the user. Unlike traditional action buttons, toggle buttons in this group retain their state after interaction, facilitating preference management.
