# OrionToggleButton

## Utilisation

`<o-toggle-button>` affiche un bouton à état persistant personnalisable.

Un toggle button est un bouton à état persistant qui permet d’activer ou désactiver une option unique.
Contrairement à un bouton d’action classique, il conserve son état après interaction et reflète visuellement si l’option est active ou inactive.
