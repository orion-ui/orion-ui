# OrionToggleButtonGroup

`<o-toggle-button-group>` est un ensemble de boutons à état persistant qui permettent de sélectionner une ou plusieurs options parmi plusieurs choix. 
Il doit être utilisé avec des composants `<o-toggle-button>` en tant qu'enfants.

Chaque bouton indique clairement son état, actif ou inactif, offrant ainsi une interface intuitive pour l'utilisateur. Contrairement aux boutons d'action traditionnels, les boutons toggle dans ce groupe conservent leur état après interaction, facilitant la gestion des préférences.
